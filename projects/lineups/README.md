# Lineups project skills

Skills for the Lineups stack: the `Lineups` Unreal Engine 5.3 repo and the
Ascent direct-container lab (`LineupsAscentLab`, `LineupsAscentLabWork`).
They extend the general skills in [`skills/`](../../skills/) and need them
installed alongside.

| Skill | Extends | Adds |
|---|---|---|
| `lineups-deslop` | `deslop` | Per-tree profiles, checkpoint rule, gates, boundaries |
| `lineups-deslop-organize` | `deslop-organize` | Doc owners, layouts, move traps |
| `lineups-deslop-reduce` | `deslop-reduce` | Analyzers, duplicate families, GPU timing |

Per-tree profiles live in `skills/lineups-deslop/references/`
(`ascentlab.md`, `lineups.md`). The two sub-skills link to them by relative
path, so install all three side by side.
